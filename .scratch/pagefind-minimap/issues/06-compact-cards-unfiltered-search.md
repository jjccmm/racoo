# Kompakte Karten und ungefilterte Zehnwortsuche

Status: claimed
Blocked by: none

## Acceptance criteria

- [x] Alle zeigt passende, lesbare Achsentitel und kleine Balkenabstände ohne horizontales Scrollen.
- [x] Ergebnisüberschrift lautet nur „Top 10 Folgen“; Rang größer, Headerplay nur als Icon oben rechts.
- [x] Texthöhe ungefähr 20 Prozent geringer, links ausgerichteter Text ohne zentrierten Einschub, Wortlegende und Fundstellennavigation in einer Zeile.
- [x] Fundstellen-Titel und Kartenfußtext entfallen; Zeitknöpfe und Anfangssprung bleiben.
- [x] Player mit zentriertem SVG-Schließenicon, ohne Zusatzaktionen, oberhalb des Audioelements nur der Werbehinweis neben dem Folgentitel.
- [x] Bis zehn verschiedene Stichwörter mit zehn Farben, Hinweis erst bei Überschreiten. Alle eingegebenen Wörter werden durchsucht; keine aktiven Stoppwort-/Ausschlusslisten.
- [x] Logoabstand auf Podcastseite reduziert; Mobil/Desktop, Datenbindung und reale 106 Folgen geprüft.
