# Lokaler Fünf-Folgen-Pilot

Der aktuelle Pilot verwendet grobe Segmente und temporäres Audio gemäß [Spezifikation](../../.scratch/local-five-episode-pilot/spec.md). Die fünf ausgewählten Folgen werden mit Parakeet FP32 auf der lokalen GPU neu verarbeitet; die gemessenen Ergebnisse und Befehle werden nach dem Integrationslauf hier ergänzt. Eine unabhängige menschliche Suchqualitätsprüfung wird damit nicht vorgetäuscht.
